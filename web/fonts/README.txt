panda_sans.png and panda_sans.json (CHANGE 150): the printable ASCII letters of Panda3D's built-in default font (the one every TextNode in the games' windows writes in), drawn by Panda3D itself and laid out by make_font.py, so the page's Fight Lab writes its rings' names, screens and fighters' numbers in the window's letters. That font is Perspective Sans (persans.ttf), compiled into Panda3D: Panda's source (panda/src/text/default_font.cxx) says it came from Font Squirrel as freeware, with no licence text; Panda3D's own BSD licence covers Panda's code, not this font. To check before release, or swap both the windows (text-default-font) and this file for an SIL OFL font.
