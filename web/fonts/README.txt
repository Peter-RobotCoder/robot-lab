JetBrains Mono (https://github.com/JetBrains/JetBrainsMono), its Latin subset as jetbrainsmono-latin.woff2 (the same file the Club Coders website uses), the code panel's font (CHANGE 138) and Craft Lab's dev panel. Copyright 2020 The JetBrains Mono Project Authors. It is licensed under the SIL Open Font License, Version 1.1: the licence is in OFL.txt beside it. Served by the VPS with the page, so school networks need not reach a font server.

Inter (https://github.com/rsms/inter), its Latin subset as inter-latin.woff2 (the website's own file): the body text of Craft Lab's HUD and screens on the page, as the window's (engine/fonts/Inter-Regular.ttf and Inter-SemiBold.ttf). Copyright 2016 The Inter Project Authors. Licensed under the SIL Open Font License, Version 1.1 (OFL.txt).

Space Grotesk (https://github.com/floriankarsten/space-grotesk), its Latin subset as spacegrotesk-latin.woff2 (the website's own file): the titles of Craft Lab's screens and the Esc menu, as the window's (engine/fonts/SpaceGrotesk-Bold.ttf). Copyright 2020 The Space Grotesk Project Authors. Licensed under the SIL Open Font License, Version 1.1 (OFL.txt).

Press Start 2P (https://github.com/codeman38/PressStart2P), its Latin subset as pressstart2p-latin.woff2 (the website's own file): only the small pixel labels, Craft Lab's slot counts, as the window's (engine/fonts/PressStart2P-Regular.ttf). Copyright 2012 The Press Start 2P Project Authors. Licensed under the SIL Open Font License, Version 1.1 (OFL.txt).

cc_sans.png and cc_sans.json: the printable ASCII letters of Inter (https://github.com/rsms/inter), the font every TextNode in the games' windows writes in (engine/fonts/Inter-Regular.ttf, made the windows' default by engine/club_fonts.py), drawn by Panda3D and laid out by make_font.py, so the page's Fight Lab and Robot Lab write their rings' names, screens and fighters' numbers in the window's letters (CHANGE 150). Copyright 2016 The Inter Project Authors. Inter is licensed under the SIL Open Font License, Version 1.1: OFL.txt beside it names every font here. (Till Craft Lab's licence fixes these were panda_sans.*, drawn from Panda3D's built-in Perspective Sans, a freeware font with no licence text; neither the windows nor the page use it now.)
